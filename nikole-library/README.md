# Мир Николь — библиотека сказок

Сайт: https://jaegermaxim-beep.github.io/moi-dela/nikole-library/

Статус: рабочий прототип с 6 историями, в каждой 10 страниц текста и временная иллюстрация. Финальные 60 картинок пока не импортированы.

## Функции
- 6 неповторяющихся историй, включая Собачку Аф и кошечку Клео
- Листание свайпом, кнопками или стрелками клавиатуры
- Избранное
- Импорт до десяти изображений для выбранной книги из файлов iPhone
- Уменьшение размера картинки и хранение только на устройстве через IndexedDB
- PWA и офлайн-кэш сайта после первого открытия

## Подготовка изображений
Исходные картинки рекомендуется держать только в личном Dropbox в отдельных папках. Для импорта скачайте нужные 10 страниц на устройство через приложение Dropbox, затем откройте книгу и выберите «Добавить картинки». Названия файлов предварительно лучше пронумеровать 01–10. Изображения сортируются по имени в натуральном порядке.

## Важные ограничения
- Dropbox не подключен автоматически. Для закрытой папки нужна авторизация OAuth PKCE, которой пока нет.
- Все текстовые истории демонстрационные, настоящие страницы ещё не сопоставлены.
- Удаление PWA или очистка данных Safari может удалить локальные картинки. Dropbox должен оставаться источником оригиналов.
- Изображения не публикуются в открытый GitHub и не синхронизируются между устройствами.
- Пока не проверено живое поведение на iPhone.
