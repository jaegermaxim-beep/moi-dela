# Облачная синхронизация «Мои дела»

**Статус:** функция находится в экспериментальной ветке `feature/cloud-sync`.
Она не включена на основном сайте, пока владелец не настроит Supabase
и мы не проверим сохранность данных.

## Подключение к созданному бесплатному проекту

**Проект создан 21.10.2026:** `moi-dela-sync` (Supabase, `eu-central-1`).
Стоимость создания по ответу Supabase: **$0 в месяц**, бесплатный тариф с лимитами.
Миграция `supabase-schema.sql` выполнена. В таблице включены RLS и три политики;
анонимное чтение запрещено; проверка Supabase Security Advisors — без замечаний.
В бета-код `sync.js` уже записаны **только публичные** Project URL и Publishable key.

1. В панели проекта Supabase → **Authentication → URL Configuration** укажи **Site URL** `https://jaegermaxim-beep.github.io/moi-dela/` и добавь такой же URL в Redirect URLs. Это необходимо для подтверждения email и восстановления пароля.
2. В **Authentication → Providers → Email** оставь email/password включённым. Проверку email лучше оставить включённой.
3. Прежде чем включать на iPhone, экспортируй и проверь **зашифрованную резервную копию** всех задач в «Ещё».
4. После отдельной проверки и обновления основного сайта открой «Ещё → Синхронизация устройств». Адрес Supabase и Publishable key будут заполнены автоматически. Зарегистрируйся по email, подтверди письмо, затем войди.
5. На ноутбуке открой тот же сайт и войди с той же почтой и паролем.
6. После тестирования импортировать задачи заново **не надо**: существующие записи iPhone должны сохраниться в IndexedDB и объединиться с облаком.

**Никогда не вводить** `sb_secret_...` или `service_role` в приложение,
не присылать пароль третьим лицам и не публиковать секреты на GitHub.
Publishable key — открытый, RLS ограничивает доступ к данным.

## Как работает

- Приложение сначала сохраняет задачи локально.
- После входа и при наличии интернета отправляет изменения в облако.
- После синхронизации забирает новые версии данных с других устройств.
- Если устройства офлайн, изменения остаются локально и будут
  синхронизированы после подключения к интернету и открытия приложения.
- Удаление также синхронизируется. При одновременном редактировании
  одной задачи на двух устройствах выигрывает запись с более поздним
  timestamp: **это ограничение**, а не гарантированный бесконфликтный
  merge. Желательно не редактировать одновременно одну и ту же задачу.
- **Облачные записи не зашифрованы end-to-end.** Они защищены
  логином, правилами RLS и HTTPS, но доступны в административной
  панели твоего Supabase проекта. Для более высокой конфиденциальности
  потребуется отдельное end-to-end шифрование.

## Не перепутать устройства и пользователей

- Задачи на iPhone сейчас в отдельной IndexedDB. Установка на ноутбуке
  создаст ещё одну локальную IndexedDB до первого входа.
- Для синхронизации нужно войти в **один и тот же Supabase-аккаунт**.
- Перед подключением другого аккаунта обязательно экспортировать
  локальные данные: это персональное одно-пользовательское приложение.
- Не удалять иконку iPhone при обновлении.

## Важное

GitHub Pages публикует только код. Все пользовательские данные
хранятся в локальной базе браузера и в приватной таблице Supabase
при включённой синхронизации. Проект может иметь бесплатные лимиты.
