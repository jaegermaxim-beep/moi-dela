# Мои дела · версия 1.1 · Solar Horizon

Независимый локальный органайзер для iPhone: задачи, проекты, события, цели, фильмы, места и путешествия. Сделан без внешних библиотек. Русский интерфейс, адаптация под iOS, светлая/тёмная тема.

## Установка на GitHub Pages

1. Создайте **пустой публичный** репозиторий, например `moi-dela`.
2. Разместите в **корне** репозитория файлы `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `apple-touch-icon.png`.
3. GitHub → Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. Дождитесь публикации (обычно несколько минут) и откройте точный адрес, показанный в Settings → Pages.
5. На iPhone откройте сайт в **Safari** → Поделиться → На экран Домой → Добавить.

## Как перенести личные записи

Личные данные **не включены** в этот репозиторий. При наличии отдельного файла `moi-dela-lichnyi-import.json`:

1. Сохраните JSON в «Файлы» на iPhone.
2. Откройте приложение через иконку на главном экране.
3. Перейдите в «Ещё» → «Восстановить из файла» → выберите JSON → «Импортировать».
4. Приложение объединит данные. Проверка на повторы выполняется по типу, категории и названию.

Можно вместо файла вставить текст из Apple Notes: Ещё → Импорт из Apple Notes.

## Приватность и сохранность

- Личные записи хранятся в IndexedDB на текущем устройстве. Если IndexedDB недоступна, используется localStorage. Если и она недоступна — выдаётся предупреждение.
- Репозиторий GitHub Pages содержит **только код приложения**. Содержимое задач туда не отправляется.
- В приложении нет авторизации, аналитики, рекламных SDK и удалённого API.
- Для резервирования доступны обычные JSON-копии и зашифрованные файлы с PBKDF2-SHA256 (250 000 итераций) и AES-256-GCM. Пароль не сохраняется.
- Данные в Safari и установленной версии могут не совпадать. Используйте приложение с иконки. До удаления иконки сохраните резервную копию в «Файлы» или iCloud Drive.
- Браузерное хранилище не является эквивалентом iCloud Sync. Без копии возможна потеря записей при очистке данных приложения или сбое устройства.

## Функции версии 1.0

- Задачи: статусы, сроки, приоритеты, поиск, группы по срокам, связь с проектами.
- Проекты: индикатор прогресса по связанным задачам и подзадачам.
- События: даты, время, экспорт iCalendar `.ics`.
- Коллекции: места с детьми, путешествия, фильмы, цели, заметки.
- Универсальный поиск по названию, описанию, категории, локации и URL.
- Импорт из Apple Notes, импорт JSON с устранением точных дублей.
- Светлая и тёмная тема, offline-first PWA через Service Worker.

## Ограничения

- Нет синхронизации между устройствами и автоматического фонового резервного копирования.
- Нет отправки push-уведомлений и прямого создания Apple Reminders.
- Нет умной AI-классификации, геокарт и голосового ввода — это варианты будущего развития.
- Нельзя импортировать изображения и вложения из Apple Notes.
- `localStorage` — аварийный вариант при недоступности IndexedDB и менее устойчив к потере данных.
- В этой версии нет автоматического разрешения конфликтов при импорте отредактированных копий одного и того же объекта.

## Технологии

Статический HTML, CSS, JavaScript, IndexedDB, Web Crypto, Service Worker. Для сборки ничего не требуется.
